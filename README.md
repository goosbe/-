Это программа для определения цвета
В программе есть разделение на под группы (то есть: группы по цвету, красный, ораньжевй и тд, так же они расположенны по порядку ргб)
В группах так же сделанно по порядку, сначала светлые и всё темнее и темнее(это немного не доработанно)
Как использовать:
Сама программа написанна на pycharm, фото должно лежать в папке с скриптом.
